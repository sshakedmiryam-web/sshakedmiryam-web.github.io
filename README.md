# שקד אשתר — תיק עבודות

תיק עבודות בעיצוב דיגיטלי ופיתוח: אתרים, אפליקציות, דשבורדים, מצגות ודוגמאות קוד נבחרות.

**האתר:** https://sshakedmiryam-web.github.io/

## הרצה ועריכה

האתר סטטי ומבוסס HTML, CSS ו־JavaScript, ללא תהליך בנייה. אפשר להפעיל שרת קבצים מקומי ולפתוח את `index.html`.

- `projects.js` — תוכן העבודות והגלריות.
- `code-projects.js` — דוגמאות הקוד ותמונות התוצאות.
- `studio.js` — מעבר בין אזורי העיצוב והתכנות.
- `contact.js` — הכנת פנייה במייל או בווטסאפ; השליחה מתבצעת באפליקציית המשתמש. אין שמירת פניות בשרת.
- `images/`, `media/`, `brand/`, `fonts/` — חומרי האתר.

GitHub Pages מפרסם את ענף `main` מתיקיית השורש. קובץ `.nojekyll` מאפשר הגשת הקבצים ישירות.

המאגר כולל רק את תיק העבודות ואת קטעי הקוד שנבחרו להצגה. הוא אינו מכיל את מאגרי המקור המלאים של העבודות.

כל זכויות העיצובים, התמונות וחומרי המותג שמורות לבעליהם. אין במאגר רישיון לשימוש חוזר בחומרי תיק העבודות.
